# JustUseNan

A simple Astro site.

## Quick Start

```bash
# Install dependencies
bun install

# Start dev server
bun dev
```

## Project Structure

```text
/
├── public/
│   ├── favicon.svg
│   ├── favicon.ico
│   └── styles.css
├── src
│   ├── layouts/
│   │   └── Layout.astro
│   └── pages/
│       └── index.astro
├── astro.config.mjs
└── package.json
```

## Commands

| Command           | Action                              |
| :---------------- | :---------------------------------- |
| `bun dev`         | Start dev server at localhost:4321  |
| `bun build`       | Build production site to ./dist/    |
| `bun preview`     | Preview build locally               |

## Requirements

- Node.js 24.0.0+
- Bun
